# orca-russian

Русский языковой пакет для [Orca](https://github.com/stablyai/orca).

## Установка

Orca находит языковые пакеты через систему плагинов: укажи этот репозиторий (или локальную копию) как источник плагина, затем выбери **ru — orca-russian** в Настройки → Внешний вид → Язык.

## Состав

`locales/ru.json` — переводы каталога `en.json` из `stablyai/orca` (`src/renderer/src/i18n/locales/`). Непереведённые строки автоматически падают обратно на английский.

Набор ключей совпадает с официальным pt-BR пакетом (12 524 строки): пропущены защищённая область `auto.components.settings.plugin*`, inline-CSS и строки, отсутствующие в текущем каталоге.

## Ограничения

- Плейсхолдеры `{{value0}}`, `{{value1}}` сохраняются дословно. Там, где английская строка собирает фразу из глагола/существительного в позиционном плейсхолдере, русская морфология полностью не выводится — это ограничение формата i18n на стороне Orca.
- `worktree`, `workspace`, `PR`, названия брендов и флаги CLI оставлены без перевода.

## Правки

PR в `locales/ru.json` с сохранением структуры ключей.
